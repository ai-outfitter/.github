# AI Outfitter

Outfitter builds effective agent profiles and launches them through wrapped agent CLIs like [`pi`](https://github.com/earendil-works/pi-coding-agent), Claude Code, and future adapters. Individuals, teams, and organizations can share and compose repeatable agent profiles.

```bash
npx @ai-outfitter/outfitter
```

## Projects

- **[outfitter](https://github.com/ai-outfitter/outfitter)** — Swap between configurations in Pi; it's like dotfiles for your coding agent. Profiles compose the context, tools, prompts, skills, extensions, subagents, and DeepWork workflows that shape an agent.
- **[actions](https://github.com/ai-outfitter/actions)** — Run Outfitter profiles headless (`pi -p`) from GitHub Actions. Build your own scheduled or event-driven reviewer or task agent.
- **[default-profiles](https://github.com/ai-outfitter/default-profiles)** — The default profile catalog for Outfitter users.

## Pi extension packages

- **[deepwork](https://github.com/ai-outfitter/deepwork)** — DeepWork workflows, DeepWork Reviews, and DeepSchema, native to Pi.
- **[ulta-tasklist](https://github.com/ai-outfitter/ulta-tasklist)** — Task list extension.
- **[file-talk](https://github.com/ai-outfitter/file-talk)** — File conversation extension.
- **[bash-saver](https://github.com/ai-outfitter/bash-saver)** — Persist and reuse bash sessions.

## Getting started

New to Pi? Outfitter is the quickest path to a recommended [Pi](https://pi.dev) loadout for engineering work. See the [getting started guide](https://github.com/ai-outfitter/outfitter/blob/main/docs/documentation/getting-started.md).
