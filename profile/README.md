# AI Outfitter

Open, vendor-neutral tooling for configuring and operating agents—from
AI-assisted coding to an autonomous software development lifecycle.

**[See how AI Outfitter fits together →](https://github.com/ai-outfitter/outfitter/blob/main/docs/documentation/ai-outfitter.md)**

## Repositories

| Repository | Purpose |
| --- | --- |
| [outfitter](https://github.com/ai-outfitter/outfitter) | Compose agent configuration from plain files and launch it across supported agent CLIs. |
| [deepwork](https://github.com/ai-outfitter/deepwork) | Run structured, multi-step agent work with quality gates. |
| [link](https://github.com/ai-outfitter/link) | Catalog and inspect evidence about an organization’s agentic software-development lifecycle. |
| [actions](https://github.com/ai-outfitter/actions) | Run Outfitter profiles headlessly in GitHub Actions. |
| [agent-operator](https://github.com/ai-outfitter/agent-operator) | Provision and supervise resident agents on Kubernetes. |
| [channels](https://github.com/ai-outfitter/channels) | Deliver email, chat, and forge events to agent sessions. |
| [pensieve](https://github.com/ai-outfitter/pensieve) | Store immutable evidence from agent sessions and workflows. |
| [evals](https://github.com/ai-outfitter/evals) | Benchmark agent profiles and harnesses with reproducible, attested evaluations. |
| [autoimprove](https://github.com/ai-outfitter/autoimprove) | Improve portable agent skills against measured outcomes. |
| [default-profiles](https://github.com/ai-outfitter/default-profiles) | Provide the default catalog of Outfitter agents and skills. |
| [community-profiles](https://github.com/ai-outfitter/community-profiles) | Share community-contributed Outfitter agents and skills. |
| [.agents](https://github.com/ai-outfitter/.agents) | Hold AI Outfitter’s own shared agent catalog and reports. |
| [ulta-tasklist](https://github.com/ai-outfitter/ulta-tasklist) | Add task-list workflows to Pi. |
| [file-talk](https://github.com/ai-outfitter/file-talk) | Let Pi work with file-backed conversations. |
| [bash-saver](https://github.com/ai-outfitter/bash-saver) | Preserve useful shell commands from Pi sessions. |
| [.github](https://github.com/ai-outfitter/.github) | Maintain organization-wide GitHub defaults and this profile. |
